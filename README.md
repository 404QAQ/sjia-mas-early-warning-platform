# sJIA/MAS Early Warning Platform · sJIA 合并 MAS 动态预警平台

> 「罕见·无界」黑客松 · 赛题7 · sJIA + 合并 MAS 动态预警平台
> 依据《sJIA 合并 MAS 动态预警平台 产品需求书 V1.0》（2026-10-01）编写 · 发起方：sJIA 守护者联盟 · [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)共建

**sJIA 合并 MAS 动态监测与连续预警平台**——通过单次指标评分 + 多次指标动态变化分析，帮助患者或医生早期识别 MAS 风险，抓住治疗时机。

> 定位边界：辅助预警工具，帮助提高警惕，不替代专业诊疗判断。

## 🧭 一、疾病背景

**幼年特发性关节炎全身型（sJIA）**：儿童期最复杂的疾病之一，全身性疾病，三大主要表现为**发热、皮疹、关节炎**，以弛张热为突出表现；年发病率约 0.3–0.8/10 万，已纳入中国第二批罕见病目录；16 岁以上可表现为成人斯蒂尔病（AOSD）。诊断标准：2001 ILAR / 2019 PRINTO；确诊前需排除感染、血液肿瘤、其他风湿免疫性疾病等。

**巨噬细胞活化综合征（MAS）**：继发性噬血细胞性淋巴组织细胞增多症（HLH），严重且危及生命的过度炎症反应综合征，可继发于多种儿童风湿性疾病，**以 sJIA 最为常见，是 sJIA 后果最严重的并发症**：

- **至少 7%** 的 sJIA 患者病程中出现 MAS（还有很多患者仅表现部分临床特点而未被诊断）
- 一项 350+ 例 sJIA 相关 MAS 队列中**致死率可达 8%**
- 典型特征：快速进展的持续发热、肝脾/淋巴结肿大、肝功能异常（可至肝衰竭）、脑病、紫癜瘀斑黏膜出血；重症多器官受累（呼吸窘迫、肾衰竭、癫痫、休克）

**核心临床难题**：MAS 不同阶段临床表现缺乏特异性，**早期表现与 sJIA 不易区分**，易错失最佳治疗时机，评分标准早期诊断尤其困难。2023 EULAR/PReS 推荐：持续发热、脾大、铁蛋白升高、血细胞计数异常降低、肝功能异常、凝血激活、甘油三酯升高者均应考虑早期或亚临床 MAS。

## 📐 二、诊断标准体系

**2016 PRINTO/ACR/EULAR 主流标准**——确诊或疑似 sJIA 患者发热 + 铁蛋白 > 684 ng/mL，且具备以下任意 2 条：血小板 < 181×10⁹/L；AST > 48 U/L；甘油三酯 > 156 mg/dL；纤维蛋白原 < 360 mg/dL（3.6 g/L）。

**HLH-2004 标准**（8 条满足 5 条）：NK 细胞活性↓/sCD25↑；噬血现象；发热 >38.5°C 持续 >1 周；脾大；血细胞减少（两系或三系）；TG >3 mmol/L 或 Fbg <1.5 g/L；铁蛋白 >500 μg/L。

**MAS/sJIA（MS）评分**：中枢神经系统受累 +2.44、出血现象 +1.54、关节炎 −1.30、血小板 −0.003、LDH +0.001、纤维蛋白原 −0.004、铁蛋白 +0.0001；**MS 值 ≥ −2.1 则 sJIA 合并 MAS 可能性大**（发热为强制指标未入公式）。

## 🎯 三、为什么需要「动态预警」

早期监测 sJIA 合并 MAS **并非依赖某一次检查结果，而是需要密切观察指标的动态变化**。现实问题：地方医生常因缺乏经验，等待指标完全符合诊断标准后再干预，一定程度上延缓治疗、增加难度。因此本项目核心能力是**动态监测 + 连续预警**。

## 🛠 四、核心功能需求

**平台框架（静态 + 动态两条路径）**：

| 输入情况 | 监测方式 | 输出 |
|---|---|---|
| 仅输入 1 次指标 | 静态监测（单次指标评分） | 单次评分；未达 MAS 阈值则结束 |
| 输入 ≥2 次指标 | 静态监测 + 动态监测 | 分别有不同预警情况 |

- **静态监测**：依据 2016 PRINTO/ACR/EULAR 标准、2004 HLH 标准、MS 评分表给出单次评分
- **动态监测**：监测指标**动态变化趋势**（而非单点值）；预警灵敏度用户可调；支持为指标自定义权重；报警逻辑可设置核心指标与一般指标

**需要监测的关键指标**（依据 2023 EULAR/PReS 推荐）：

| 类别 | 指标 |
|---|---|
| 临床 | 持续发热、脾大 |
| 炎症标志物 | 铁蛋白（SF）升高或上升 |
| 血液 | 血细胞计数异常降低、血小板计数 |
| 肝功能 | AST 等肝功能指标 |
| 凝血 | 血管内凝血激活、纤维蛋白原 |
| 代谢 | 血清甘油三酯升高或上升 |
| 其他 | LDH、中枢神经系统受累、出血现象、关节炎 |

## 📋 五、非功能需求

| 类别 | 要求 |
|---|---|
| 动态性 | 核心能力是观察指标动态变化，而非单次检查结果 |
| 连续预警 | 支持连续多次输入的累积预警，而非一次性判定 |
| 可配置 | 预警灵敏度、指标权重、核心/一般指标分类均可由用户设置 |
| 可用性 | 面向患者家属与地方医生，降低使用门槛 |
| 时效性 | 尽早诊断、尽早干预，抓住最佳治疗时机 |
| 定位边界 | 辅助预警工具，不替代专业诊疗判断 |
